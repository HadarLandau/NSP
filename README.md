# Geometric Multiscale Analysis via Non-Stationary Subdivision Schemes

This repository contains the MATLAB code accompanying the paper **“Geometric multiscale analysis via non-stationary subdivision schemes.”**

The code implements the non-stationary subdivision-based pyramid transforms introduced in the paper and demonstrates their application to geometric multiscale analysis. In particular, the provided scripts reproduce the numerical experiments and figures presented in the paper, including experiments involving planar samples of circles and circles generated by a neural network.

## Overview

Pyramid transforms provide a multiscale representation of data composed of a coarse approximation of the data along with layers of details, each associated with a different scale. In the framework considered here, the usual stationary upsampling operators are replaced by **non-stationary subdivision schemes**, whose refinement rules may vary with the refinement level. This provides additional flexibility for constructing multiscale transforms and enables their application to geometric data.

The repository includes implementations for:

* non-stationary subdivision refinement;
* multiscale decomposition and computation of detail coefficients;
* two-dimensional geometric data;
* analysis of planar samples with respect to circular shapes; and
* circles generated by a neural network.

The mathematical background and theoretical properties of the methods are described in the accompanying paper.

## Repository Structure

The main MATLAB source code is located in the `src` directory.

The repository contains:

* **`run_fig*.m`** — scripts for reproducing the figures and numerical experiments presented in the paper.
* **Subdivision and refinement functions** — implementations of the non-stationary subdivision schemes used by the transforms.
* **Decomposition functions** — functions for decomposing the data into coarse approximations and detail coefficients at multiple scales.
* **Mask-generation functions** — functions defining the level-dependent subdivision masks.
* **Neural-network functions** — code related to the generation of circles using a neural network.

The individual MATLAB files contain detailed documentation describing their inputs, outputs, and implementation.

## Reproducing the Figures

The `run_fig*.m` scripts serve as the main entry points for reproducing the computational results.

To reproduce a particular figure, run the corresponding script from MATLAB. For example:

```matlab
run_fig4
```

All scripts whose names begin with `run_fig` are intended to reproduce the corresponding graphs and experiments presented in the paper.

Make sure that the `src` directory is included in the MATLAB path before running the scripts. This can be done, for example, with:

```matlab
addpath('src')
```

The exact requirements and parameters for each experiment are documented in the corresponding script.

## Geometric Multiscale Analysis

A central application of the proposed framework is the analysis of planar point sets.

The code can be used to study how well a collection of planar samples is represented by a circular geometry. The multiscale decomposition produces detail coefficients that describe deviations from a circular shape. This provides a way to identify geometric features and localized anomalies at different scales.

## Neural-Network-Generated Circles

The repository also contains an experiment involving circles generated by a neural network.

The function

```matlab
NN_circles_128pts
```

trains a neural network to generate 128 points representing a unit circle centered at a specified point. The generated point set can then be analyzed using the proposed non-stationary multiscale framework.

This experiment illustrates how the proposed framework can be applied not only to explicitly constructed geometric data, but also to geometric structures produced by a neural network.
